# Textos revisados — Bloco B

Varredura em src/: rótulos de página, indicação, horários, administração, estados e capitalização. Nomes internos de funções/rotas antigas e campos históricos não são texto de interface e foram preservados para compatibilidade.

| Antes | Depois |
|---|---|
| Conversas / Minhas conversas | Alianças / Minhas alianças |
| Convite aceito. Agora combinem um horário. | Convite aceito. Os contatos já aparecem no cartão. |
| Ver outra sugestão / Sugestão pronta | Ver outra indicação / Indicação pronta |
| Compatibilidade básica | Indicação pelas habilidades, sem IA. |
| Sugerido pela IA, com justificativa/perguntas/rascunho | Recomendada pela IA, com habilidades que ajudam |
| Acesso administrativo legado preservado… | Aviso removido |
| done / failed / códigos técnicos de erro | Concluída / Falhou / mensagem de erro em português |
| Tokens de entrada / saída | Uso da IA (tokens enviados / recebidos). Mede o custo da IA. |
| Recusar / Reprovar perfil | Não aprovar, com motivo opcional |
| aliadas · Conversas profissionais entre mulheres | aliadas · Uma conversa pode abrir novos caminhos. |
| Só se você autorizar, e mesmo assim… | Só se você autorizar e, mesmo assim,… |

“Conversa” continua no encontro e na avaliação. “Aliança” nomeia o vínculo e a página que reúne convites/contatos. “Horário” permanece somente em código/campos históricos; não há promessa de agendamento automático. Frases visíveis seguem capitalização natural; a marca aliadas permanece com a grafia escolhida.
